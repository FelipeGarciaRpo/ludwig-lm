The lab's runs with the repo's own implementation of P35 (moe_lab.py --impl repo, on the code of the patch): the
quantile rule with --balance-damp 0.5 and all 4,096 tokens of each step as its sample, and equal offsets.
Each section starts with the command that printed it, run from results/diagnostico_moe/.
